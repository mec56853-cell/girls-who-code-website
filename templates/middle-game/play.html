Before you play

Three ideas power this adventure

1

Events

An arrow-key press is an event. It tells the computer that something happened.

2

Coordinates

The character's location is a coordinate: x counts across and y counts down.

3

Conditions

The program checks conditions: “Is this space an obstacle?” or “Did we reach the goal?”

Your code is a sequence: each numbered movement is an instruction, and Run Code tests the instructions in order.
