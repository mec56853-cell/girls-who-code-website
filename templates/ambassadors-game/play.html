Your troop is hosting a community tech day. Fix three rules in the event software before launch.

Mini lesson · How code makes a decision

Imagine your troop has a snack table. The rule is simple. Hand out snacks when there are at least 10 ready. Otherwise, wait.

if (snacksReady >= 10) {
    handOutSnacks();
} else {
    waitForMore();
}

The question in parentheses is the condition. If the answer is yes, the code hands out snacks. If the answer is no, it follows the else instruction and waits.

>= At least
10 or more snacks qualifies. Exactly 10 counts.
&& AND
If you need enough snacks and clean trays, both must be ready.
|| OR
If fruit or crackers are ready, either one works. Having both works too.

Try it in your head. With 9 snacks, the code waits. With 10 or 11, it hands them out. Trying numbers just below, at, and above the cutoff helps you catch mistakes.
